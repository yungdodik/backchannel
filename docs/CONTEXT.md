# Backchannel — context

Founder enters a fund name → gets a sourced **call list** of portfolio founders to reference-check the fund with, especially those whose companies went badly.

## Terms
- **Investor**: fund or partner the user is checking.
- **Round**: a funding round (Cala FundingRound) with date, type, amount, investors, lead flag if available.
- **Portfolio company**: any company with a Round the Investor took part in.
- **Signal**: a neutral, sourced fact about a portfolio company, e.g. "last recorded round: Mar 2023", "Cala status: closed", "domain unreachable", "founder left (source)". Never a verdict like "failed".
- **Call-list entry**: founder + company + signals (with sources) + 3 questions to ask. Founder's public writing about the fund = bonus where found.
